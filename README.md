# 小红书Cookie获取器 Chrome扩展

一个简洁、美观的Chrome扩展，用于获取小红书网站的cookie信息，便于开发与学习。扩展采用Apple风格UI设计，支持亮色/暗色主题，拥有可拖拽功能。

## 功能特点

- ✨ 自动获取小红书网站的cookie信息
- 🌓 支持亮色/暗色主题切换
- 📱 可拖拽悬浮窗，带有磁吸效果
- 📋 一键复制cookie信息
- 🔒 完全在本地运行，不会向任何服务器发送数据

## 安装方法

### 方法一：从Chrome网上应用店安装（如已发布）

1. 访问Chrome网上应用店
2. 搜索"小红书Cookie获取器"
3. 点击"添加至Chrome"按钮

### 方法二：开发者模式安装

1. 下载本项目的源代码并解压
2. 打开Chrome浏览器，在地址栏输入：`chrome://extensions/`
3. 在右上角开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择解压后的扩展目录（包含manifest.json的文件夹）


## 使用说明

1. 安装扩展后，访问小红书网站（如 https://www.xiaohongshu.com/）
2. 确保已经登录到你的小红书账号
3. 扩展会自动在页面右上角显示一个悬浮窗
4. 悬浮窗中会显示当前网站的cookie信息
5. 点击"复制"按钮即可将cookie信息复制到剪贴板

### 其他操作

- **拖拽悬浮窗**：点击悬浮窗顶部并拖动可调整位置
- **主题切换**：点击主题图标可在亮色/暗色主题间切换
- **隐藏悬浮窗**：点击关闭按钮可临时隐藏悬浮窗（刷新页面后会重新显示）
- **调整文本区域高度**：拖动文本区域右下角可调整高度
